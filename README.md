# Space Exploration Web Application

Welcome to the Space Exploration web project, a lightweight, visually striking dark-themed website crafted using clean HTML5 and modern CSS3.

## Key Features
- **Interactive Home Page:** Features responsive planet cards for Earth, the Moon, and Mars, allowing users to navigate seamlessly across space topics.
- **Dedicated Detail Pages:** Each celestial body page provides concise facts, custom glowing image highlights tailored to the planet, and personalized tab favicons.
- **Pure CSS Layout & Styling:** Built using flexbox for precise alignment, subtle hover states, smooth transitions, and a dark space aesthetic.
- **Fast & Responsive:** Designed with lightweight asset handling for quick load times across modern desktop browsers.

## Quick Start
1. Clone or download this project repository to your local device.
2. Place all image assets (`darker-earth-x.jpg`, `darker-moon-x.jpg`, `darker-mars-x.jpg`, `astronaut.jpg`) in the project root folder.
3. Open `index.html` in any web browser to explore!
